**Research date:** 2026-05-21  
**Scope:** Framework-agnostic (React + Angular + Vue), MCP-native UI component kit distributed shadcn-style. Target: developers building production AI agents. Headline positioning: "MCP UI for any framework."

## Top 3 Recommendations

### 1. herald

**Why it fits:**  
"Herald" evokes announcing, broadcasting, and signaling — exactly what a UI layer does when it surfaces agent state and tool calls to a user. It is short (6 letters), immediately pronounceable in any language, and carries a sense of authority without being aggressive. It scales naturally beyond MCP: a herald announces anything — reasoning traces, plan trees, agent events. The word is used in English literary and professional contexts without negative connotations.

A kestrel is a small, fast, highly agile falcon known for precision hovering — an apt metaphor for a UI kit that precisely surfaces agent state without getting in the way. ## Methodology Notes

1. **npm scope checks** were performed using `npm view @<name>/core` and `npm view @<name>/react` — a 404 error confirms the scoped package does not exist. The npm scope itself (`@name`) is claimed when the first scoped package under it is published; an empty scope means no one has published under it yet. We also checked unscoped `npm view <name>` to surface brand-level conflicts even if the scope is free.

2. **Domain availability** was checked via `who.is/whois/<name>.<tld>`. The `.dev` TLD (owned by Google) does not always return WHOIS data for unregistered domains; "No WHOIS data found" is treated as a strong signal of availability, not a definitive confirmation. Explicitly confirmed-registered domains returned creation/expiry dates. **All "LIKELY FREE" assessments should be confirmed with a live registrar check (e.g., Namecheap, Google Domains) before proceeding.**

3. **GitHub conflict checks** used `site:github.com` web searches and general searches for `"<name>" ui library` to catch conflicts in the developer tooling space. Minor conflicts in unrelated domains (observability, hardware, blockchain) were noted but not treated as disqualifying for names where the UI/agent space is clean.

4. **Whois.com** returned security/CAPTCHA pages for several queries and was not usable; all domain lookups were performed via `who.is` instead.

5. **The `.ui` TLD** is not a real generic TLD as of this research date and was not checked.

6. Approximately 23 distinct names were researched with varying depth. Priority was given to the 20 candidates with clearest GO/SKIP signals.
