## Commands

### `init`

Initialize mcp-elements in your project.

```bash
npx mcp-elements init
```

Creates a `mcp-elements.json` configuration file and sets up the output directory structure.

### `add`

Add one or more components to your project.

```bash
npx mcp-elements add <component...>
```

Examples:

```bash
npx mcp-elements add button
npx mcp-elements add card input textarea
npx mcp-elements add dialog --framework react
```

The CLI automatically resolves internal dependencies. For example, `npx mcp-elements add dialog` also copies `button` since Dialog depends on it.
